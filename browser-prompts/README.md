# Paste-ready prompts

Four files, in plain view rather than inside the hidden `.claude` directory. Open the one that matches your situation, copy the block inside it, and paste it into your assistant.

- [claude-code.md](claude-code.md) is the nudge to use if Claude Code answers like a general chatbot instead of a security coach. Most of the time you will not need it, because Claude Code reads this folder by itself.
- [codex-cli.md](codex-cli.md) is the one prompt to paste at the start of a Codex CLI session inside this folder.
- [limited-browser-mode.md](limited-browser-mode.md) is for ChatGPT, Claude in a browser, or any other chat window on a website. It points to one visible file, [security-browser-kit.md](security-browser-kit.md), that contains the browser-ready instructions and jobs.
- [install-the-assistant.md](install-the-assistant.md) is for people who do not have Claude Code or the Codex CLI yet. Paste it into whatever assistant you already have open and it will walk you through the install.

None of these replaces downloading the folder. They are how you switch the downloaded folder on inside the assistant you use.

Anything you type, paste, or attach is sent to the assistant's provider as part of the conversation. Redact passwords, codes, account numbers, and other secrets first.

If you are running Claude Code or the Codex CLI in this folder, the shortest path is to type `Start the kit` and skip all four files.
