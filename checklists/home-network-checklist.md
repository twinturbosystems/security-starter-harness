# Home network checklist

Filled in by `/home-network`. One evening, one router. Check a box when the item is done and add the date. Do not write the Wi-Fi password, the admin password, or the router address in this file; record only that the step was done.

- [ ] Item 1, admin password changed from the default and stored in the password manager. Date:
- [ ] Item 2, firmware updated, automatic updates turned on if available. Date:
- [ ] Item 3, guest network on, smart devices and visitors moved to it. Date:
- [ ] Item 4, remote administration off (and WPS and UPnP off if they were easy to find). Date:
- [ ] Item 5, Wi-Fi set to WPA3 or WPA2 with a password of at least 12 characters, different from the admin password. Date:

Optional extras:

- [ ] Wi-Fi network renamed to something that does not identify the household or business
- [ ] Connected-devices list reviewed, unknown devices noted below
- [ ] DNS left on automatic unless set on purpose
